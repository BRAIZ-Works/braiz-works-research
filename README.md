# BRAIZ Works Research

BRAIZ Works Research is the public research and technical-report library of BRAIZ Works LLC.

This repository publishes public-safe research papers, citation metadata, versioned release artifacts, and integrity manifests while preserving a strict boundary around proprietary implementation details, private evidence, credentials, internal prompts, and reconstruction-sensitive architecture.

## Research papers

- **WP-02 — The Enterprise Execution Gap** — Why AI activity is not the same as governed outcome closure.

## Publication model

Each paper has a stable paper ID and version. Versioned public artifacts are distributed through GitHub Releases, linked from the reader-facing research library, and accompanied by SHA-256 integrity information and citation metadata. Corrections use successor versions; released history is not silently overwritten.

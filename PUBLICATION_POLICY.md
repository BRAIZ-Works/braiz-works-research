# Publication Policy

BRAIZ Works Research uses a versioned, evidence-aware publication model.

1. Repository source and a formal versioned release are distinct surfaces; the release record defines the exact distributed version.
2. Each public release uses an exact approved version and release identity.
3. Released paper files and release assets are not silently replaced. Corrections use a successor version.
4. Public artifacts exclude credentials, private owner/admin evidence, internal prompts, protected implementation mechanics, and reconstruction-sensitive materials.
5. Consequential factual claims are supported by cited public evidence or clearly identified as BRAIZ Works analysis, thesis, or framework language.
6. Public release artifacts receive SHA-256 integrity records.
7. Reader-facing pages link to the exact release version they describe.
8. A later BRAIZWorks.com mirror may link to these releases but does not replace their version identity.
